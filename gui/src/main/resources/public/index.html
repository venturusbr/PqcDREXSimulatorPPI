Drex flows per algorithm

Runs the 19 use-case flows once per signer, each with fresh accounts and contracts, checking the on-chain state of every flow. Reports pass/fail, gas and bytes per flow and algorithm. About 3 minutes.

Security tests

Forged and tampered transactions for every algorithm, a simulated quantum adversary that knows every ECDSA private key (against a classical and a hybrid deployment), and known contract flaws. About 3 minutes.

Load test

Clients of two banks paying each other at increasing rates. Reports included TPS, latency, block fill and the gas-bound ceiling.
